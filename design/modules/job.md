# Module Specification: job

- Target source file path: `src/pixelbonus/job/worker.go`
- Owned APIs:
  - `NewWorker`
  - `Worker.Run`
- Internal logic:
  - Poll for queued jobs every second.
  - For a claimed job:
    - load course information
    - generate coupon tokens
    - derive PDF file nonce and output path
    - render PDF
    - persist generated set and file metadata
    - send notification email with absolute download URL
  - On any failure after claim, call `FailJob`.
  - Honor context cancellation between polling cycles and before long-running steps.
- Dependencies ONLY via `design/api.md`:
  - `coupon.ClaimNextJob`
  - `coupon.CompleteJob`
  - `coupon.FailJob`
  - `course.GetCourse`
  - `pdf.RenderCoupons`
  - `email.Send`
