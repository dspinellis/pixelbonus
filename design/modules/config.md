# Module Specification: config

- Target source file path: `src/pixelbonus/config/config.go`
- Owned APIs:
  - `Load`
- Internal logic:
  - Define the `Config` struct for server address, database path, schema path, templates path, assets path, privacy policy path, PDF directory, base URL, TLS certificate paths, mail command path, and session cookie security settings.
  - Read environment variables and apply deterministic defaults suitable for local tests.
  - Defaults:
    - address `:8443`
    - database path `./pixelbonus.db`
    - schema path `./design/schema.sql`
    - templates path `./src/templates`
    - assets path `./src/assets`
    - privacy policy path `./privacy_policy.md`
    - PDF directory `/var/tmp/pixelbonus`
    - base URL `https://pixelbonus.com`
    - TLS files from the specified letsencrypt paths
    - mail command `/usr/bin/mail`
  - Parse boolean and duration-like settings only if later added; current implementation can stay string-only except where integers are explicitly needed.
- Dependencies ONLY via `design/api.md`:
  - none
