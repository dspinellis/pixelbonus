# Module Specification: i18n

- Target source file path: `src/pixelbonus/i18n/i18n.go`
- Owned APIs:
  - `NewCatalog`
  - `ResolveLanguage`
  - `Catalog.T`
- Internal logic:
  - Keep translation strings in in-memory maps keyed by stable message keys.
  - Support exactly `en` and `el`.
  - Parse the `Accept-Language` header by scanning comma-separated tags and matching `el` or `en` prefixes.
  - Fall back to English.
- Dependencies ONLY via `design/api.md`:
  - none
