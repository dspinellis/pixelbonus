# Implementation Notes

- Anonymous CSRF protection uses a double-submit cookie token named `pixelbonus_anon_csrf`; authenticated requests use the session-backed `csrf_token`.
- Coupon QR URLs use the normalized uppercase hexadecimal token directly because it is already URL-safe.
- Sessions currently have no explicit expiry; they remain valid until logout or database cleanup.
- The public privacy policy page renders the source markdown as preformatted text instead of converting it to HTML.
- The PDF generation uses the `gofpdf` package with QR images generated by `go-qrcode`.
